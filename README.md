# HTTP/HTTPS Analyzer

Extensie Chrome aflată în dezvoltare. Interfața permite introducerea adresei unui site pentru analiză.

## Instalare în Chrome

1. Descarcă sau clonează proiectul pe calculator.
2. Deschide Chrome și accesează `chrome://extensions`.
3. Activează **Developer mode**.
4. Apasă **Load unpacked**.
5. Selectează folderul proiectului, cel care conține `manifest.json`.
6. Apasă iconița extensiei din bara Chrome pentru a deschide Analyzer.

> Proiectul este în faza de prototipare. Analiza cererilor HTTP/HTTPS va fi adăugată ulterior.
